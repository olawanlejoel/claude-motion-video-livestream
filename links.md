# Links: Making Beautiful Animations with Claude, Figma & Agent Skills

Everything mentioned in the livestream, grouped by what it's for.

## Inspiration

- **[Motion Prompt Gallery](https://motionpromptgallery.com/)**: curated motion graphics made with frontier AI models, each shown with the prompt or skill that produced it. Good for learning how to prompt for motion.
- **[What Ships](https://whatships.com/)**: an index of product launch clips and demos posted on X. Use it to study how products announce themselves before you write your own brief.
- **[Post on X by @0xMovez](https://x.com/0xMovez/status/2104216919033192746)**: the post I referenced on stream.

## Tools

- **[Remotion](https://www.remotion.dev/)**: a framework for making videos with React code. A good option if you want a proper video framework instead of the plain HTML + ffmpeg approach in the skill.
- **[Figma Chrome extension](https://www.figma.com/downloads/chrome-extension/)**: captures a live webpage or element and turns it into editable Figma layers. This is how I got a real site's UI into Figma to use as a source for the animations.
